# Project Atlas

Project Atlas is the company's new analytics warehouse. Project Atlas is owned by the Data Platform team and is scheduled to launch in Q3. The Project Atlas budget is 1.2 million USD.

# Project Beacon

Project Beacon is the customer mobile app rewrite. Project Beacon is owned by the Mobile team. Project Beacon has a budget of 800,000 USD and is scheduled to launch in Q1 2026.

# Project Cedar

Project Cedar migrates billing to a new payment provider. Project Cedar is owned by the Payments team. Project Cedar has a budget of 450,000 USD and is scheduled to launch in Q4 2025.

# Project Delta

Project Delta is the new employee self-service portal for leave requests and payslips. Project Delta is owned by the People Systems team. Project Delta has a budget of 300,000 USD and is scheduled to launch in Q2 2026.
