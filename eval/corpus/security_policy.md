# Encryption

All customer data is encrypted at rest with AES-256. Data in transit is protected with TLS 1.3.

Encryption keys are stored in the cloud key management service and rotated every 90 days.

# Access Control

Multi-factor authentication is mandatory for every employee account. Passwords must be at least 14 characters long.

Access to production systems is reviewed quarterly by the Security team.

# Incident Reporting

Suspected security incidents must be reported to security@example.com within 24 hours of discovery.
