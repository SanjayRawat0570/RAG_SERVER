# Installing the VPN Client

The company VPN uses the GlobalConnect client. Install GlobalConnect from the software center and connect to the server vpn.example.com.

# Security Keys

Every VPN connection requires a hardware security key. New employees receive a YubiKey on their first day.

# Split Tunneling

Split tunneling is disabled, so all traffic goes through the VPN while it is connected.

# VPN Troubleshooting

If the VPN client shows an error code, look it up in the IT error code reference. The IT helpdesk can reset locked VPN accounts.
