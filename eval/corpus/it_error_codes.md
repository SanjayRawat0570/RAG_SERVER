# VPN Errors

Error E-4012 means the VPN certificate has expired. Re-enroll the device in the VPN portal to get a new certificate.

Error E-4021 means the VPN account is locked after 5 failed login attempts. Contact the IT helpdesk to unlock it.

Error E-4102 means the hardware security key was not detected. Reconnect the key and restart the GlobalConnect client.

# Single Sign-On Errors

Error E-5003 means the SSO token does not match the session. Clear the browser cookies and sign in again.

Error E-5030 means the identity provider timed out. Wait 5 minutes and retry; if it persists, check the status page.

# Email Errors

Error E-6007 means the mailbox quota of 50 GB has been exceeded. Archive old messages to free space.

# Printing Errors

Error E-7101 means the printer is offline. Check the network cable and the power supply.

Error E-7110 means the printer driver is outdated. Install the latest driver from the software center.
