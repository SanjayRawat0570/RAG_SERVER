# Version 2.3.0

Version 2.3.0 was released on 10 February 2025. It added single sign-on with SAML and deprecated the Orders API v1.

# Version 2.3.1

Version 2.3.1 was released on 24 February 2025. It fixed bug BUG-1893, which caused CSV exports to time out.

# Version 2.4.0

Version 2.4.0 was released on 7 April 2025. It added the new analytics dashboard, which is built on Project Atlas, and increased webhook retries to 6 attempts.

# Version 2.4.1

Version 2.4.1 was released on 21 April 2025. It is a security patch for CVE-2025-1182 in the PDF export.
