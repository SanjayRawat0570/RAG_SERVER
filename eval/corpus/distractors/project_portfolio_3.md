# Project Nimbus

Project Nimbus is the migration of build pipelines. Project Nimbus is owned by the Partner Portal team. Project Nimbus has a budget of 220,000 USD and is scheduled to launch in Q4 2026.

# Project Onyx

Project Onyx is a new internal search index. Project Onyx is owned by the Integrations team. Project Onyx has a budget of 910,000 USD and is scheduled to launch in Q1 2026.

# Project Pioneer

Project Pioneer is a fraud scoring service. Project Pioneer is owned by the Search team. Project Pioneer has a budget of 220,000 USD and is scheduled to launch in Q2 2026.

# Project Quarry

Project Quarry is a translation memory service. Project Quarry is owned by the Localization team. Project Quarry has a budget of 1.5 million USD and is scheduled to launch in Q2 2026.
