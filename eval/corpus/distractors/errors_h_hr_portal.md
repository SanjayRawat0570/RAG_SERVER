# HR Portal Connection Errors

Error H-5300 in the HR Portal means the local cache is corrupted. Clear the application cache.

Error H-4021 in the HR Portal means the configuration file is missing a value. Restore the default configuration.

Error H-4012 in the HR Portal means the network proxy rejected the connection. Contact the network team.

# HR Portal Account Errors

Error H-6007 in the HR Portal means the local cache is corrupted. Clear the application cache.

Error H-5030 in the HR Portal means the upstream service did not answer in time. Retry after a few minutes.

Error H-6007 in the HR Portal means the device clock is out of sync. Enable automatic time sync.

# HR Portal Data Errors

Error H-5300 in the HR Portal means the local cache is corrupted. Clear the application cache.

Error H-7110 in the HR Portal means the file format is not supported. Convert the file and upload it again.

Error H-4012 in the HR Portal means the record was modified by someone else. Reload the record and repeat the change.
