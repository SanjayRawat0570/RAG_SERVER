# Expense App Connection Errors

Error X-5030 in the Expense App means the upstream service did not answer in time. Retry after a few minutes.

Error X-4012 in the Expense App means the user lacks the required role. Request the role in the access portal.

Error X-5300 in the Expense App means the session cookie is missing. Sign out and sign in again.

# Expense App Account Errors

Error X-6007 in the Expense App means the upstream service did not answer in time. Retry after a few minutes.

Error X-5030 in the Expense App means the request payload is too large. Reduce the size and retry.

Error X-4012 in the Expense App means the local cache is corrupted. Clear the application cache.

# Expense App Data Errors

Error X-4102 in the Expense App means the file format is not supported. Convert the file and upload it again.

Error X-5030 in the Expense App means the badge has been deactivated. Visit reception to reactivate the badge.

Error X-4021 in the Expense App means the session cookie is missing. Sign out and sign in again.
