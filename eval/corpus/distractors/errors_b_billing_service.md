# Billing Service Connection Errors

Error B-4120 in the Billing Service means the session cookie is missing. Sign out and sign in again.

Error B-4120 in the Billing Service means the network proxy rejected the connection. Contact the network team.

Error B-4021 in the Billing Service means the request payload is too large. Reduce the size and retry.

# Billing Service Account Errors

Error B-5300 in the Billing Service means the account has no license assigned. Ask your manager to assign a license.

Error B-5300 in the Billing Service means the record was modified by someone else. Reload the record and repeat the change.

Error B-6007 in the Billing Service means the file format is not supported. Convert the file and upload it again.

# Billing Service Data Errors

Error B-7110 in the Billing Service means the user lacks the required role. Request the role in the access portal.

Error B-6007 in the Billing Service means the local cache is corrupted. Clear the application cache.

Error B-4012 in the Billing Service means the record was modified by someone else. Reload the record and repeat the change.
