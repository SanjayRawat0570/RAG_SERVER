# Badge Access Connection Errors

Error A-4102 in the Badge Access means the account has no license assigned. Ask your manager to assign a license.

Error A-4012 in the Badge Access means the session cookie is missing. Sign out and sign in again.

Error A-7101 in the Badge Access means the record was modified by someone else. Reload the record and repeat the change.

# Badge Access Account Errors

Error A-7110 in the Badge Access means the local cache is corrupted. Clear the application cache.

Error A-5030 in the Badge Access means the device clock is out of sync. Enable automatic time sync.

Error A-5003 in the Badge Access means the configuration file is missing a value. Restore the default configuration.

# Badge Access Data Errors

Error A-6007 in the Badge Access means the device clock is out of sync. Enable automatic time sync.

Error A-5003 in the Badge Access means the device clock is out of sync. Enable automatic time sync.

Error A-5300 in the Badge Access means the user lacks the required role. Request the role in the access portal.
