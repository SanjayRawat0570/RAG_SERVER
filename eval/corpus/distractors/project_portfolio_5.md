# Project Vertex

Project Vertex is automated invoice reconciliation. Project Vertex is owned by the Data Science team. Project Vertex has a budget of 380,000 USD and is scheduled to launch in Q2 2026.

# Project Willow

Project Willow is a redesign of the partner onboarding flow. Project Willow is owned by the Security Operations Center team. Project Willow has a budget of 380,000 USD and is scheduled to launch in Q1 2025.

# Project Zephyr

Project Zephyr is a fraud scoring service. Project Zephyr is owned by the Design Systems team. Project Zephyr has a budget of 380,000 USD and is scheduled to launch in Q1 2026.

# Project Aurora

Project Aurora is the consolidation of monitoring dashboards. Project Aurora is owned by the Infrastructure team. Project Aurora has a budget of 1.5 million USD and is scheduled to launch in Q1 2025.
